# 📜 Automation Scripts

The project includes purpose-built scripts under [`scripts/`](../scripts/) to automate setup, deployment, text generation, and audio synthesis:

| Script                                                               | Responsibility                                                                                                                                                                                                                         | Typical Usage                                                |
|----------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------|
| [`scripts/setup-pi.sh`](../scripts/setup-pi.sh)                       | One-time Raspberry Pi environment bootstrapper. Installs Java 21 via SDKMAN!, `mpv`, `libgpiod`, sets group permissions (`gpio`, `dialout`, `audio`, `systemd-journal`), creates `~/audio`, and enables user lingering for auto-start. | `bash scripts/setup-pi.sh`                                   |
| [`scripts/deploy.sh`](../scripts/deploy.sh)                           | Automated remote deployment. Builds the fat JAR (`mvnw package`), syncs audio to the Pi via `rsync`/`scp`, deploys the `storybox.service` systemd unit, and triggers service reload over SSH.                                          | `./scripts/deploy.sh [--skip-build] [--skip-audio] [--logs]` |
| [`scripts/storybox.service`](../scripts/storybox.service)             | Systemd user unit configured for unattended auto-start on boot with automatic restart on failure.                                                                                                                                      | Managed via `scripts/deploy.sh` & `systemctl --user`         |
| [`scripts/stories/gen-stories.sh`](../scripts/stories/gen-stories.sh) | Batch text generator. Reads `.stories[]` from `stories.json`, resolves labels, calls Ollama or Thaura AI with the system prompt, and outputs `stories-src/<key>.txt`.                                                                  | `./scripts/stories/gen-stories.sh [stories.json] [out-dir]`  |
| [`scripts/tts/gen-audio.sh`](../scripts/tts/gen-audio.sh)             | Batch TTS audio generator. Synthesizes spoken axis option cues (`audio/cues/*.mp3`) and static story audio (`audio/stories/*.mp3`) using Kokoro, Chatterbox, Piper, or eSpeak-ng.                                                      | `./scripts/tts/gen-audio.sh [stories.json] [audio-dir]`      |
